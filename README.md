# ____yk4x Android

Phone-friendly Android WebView wrapper for the ____yk4x GitHub Pages app.

## Build APK on GitHub
1. Upload this project's contents to a GitHub repository.
2. Commit to `main`.
3. Open **Actions → Build Android APK**.
4. Wait for the run to turn green.
5. Open the run and download **yk4x-debug-apk**.

The app uses HTTPS and Android WebView. WebView supports JavaScript and page navigation; it is not a full browser engine/UI by itself.
